# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
credentials, tokens, personal data, or exploit details in public discussions.

Use GitHub's private vulnerability reporting feature for this repository. Share
the affected area, reproduction steps, impact, and any suggested mitigation.
The maintainers will acknowledge the report and coordinate a fix before public
disclosure.

## Supported version

The current production version on `main` is supported. Older commits and
archived repositories are not maintained.
