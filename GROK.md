# Grok Development Guidelines

Read and follow `AGENTS.md` first. Canonical agent workflows live in
`.codex/skills`; `.grok/skills` provides Grok-compatible entry points.

Use Bun from the repository root and preserve the original monochrome brand and
logo. Feature branches must use `feat/<kebab-case>` and commits must follow the
Angular Conventional Commits policy in `AGENTS.md`.
